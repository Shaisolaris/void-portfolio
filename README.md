# VOID

AI-native creative portfolio in a brutalist design language.

**[Live Demo](https://shaisolaris.github.io/void-portfolio/)**

## Features

- Brutalist typographic system
- Project case sections
- WebGL-flavored visual moments
- Unconventional navigation

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Tech

Next.js · React · Tailwind CSS
